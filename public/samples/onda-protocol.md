# Onda protocol — the short version

How Onda Lab runs a shared session. Three rules, and the rest follows.

## 1. Declare before you produce

Every session starts with one sentence: what is this session for. If it cannot
be written in one sentence, it is two sessions.

## 2. One artifact per decision

A decision is only real when it has an artifact that says what changed. Chat is
where it is argued; the artifact is where it lives.

## 3. Leave the boundary behind

When a session ends, the boundary it created stays in the workspace: what was
included, what was excluded, and who decided.
