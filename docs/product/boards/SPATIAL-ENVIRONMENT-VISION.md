# 空间工作环境 — 设计与交互愿景

**Date:** 2026-11-22 · **Status:** [P] 愿景驱动设计稿（创始人已选 Q-C = C2：空间是完整工作环境，不是视图）。
**方式**：先写场景和界面原话，再写结论。不是技术方案——不涉及 schema、服务、性能。
**上游**：`docs/research/malleable-context-space/`（研究依据）、`docs/development/boards/HUABU-PLAN.md`（功能路线）、现状 = boards（cards/edges/sections）。

---

## 1. 一句话

**空间是一张你和 Coworker 共同工作的桌子：东西放在这里、摆在这里、想在这里，它记得你摆过的一切。**

## 2. 三个场景（先看场面）

### 场景 A — 早上回来
昨晚你在空间里把 5 篇论文摘要卡摆成两堆，中间画了个问号，圈出右边两张写了句"这两矛盾"。今早打开 Thylas：
- 两堆卡还在原位，问号还在，圈注还在原处。
- 右侧一条窄栏写着："Mira 昨晚把你圈的两张读完了，在下面贴了一张对比卡。" 一张新卡落在圈注旁边，盖着 Mira 的头像角标。
- 你把问号拖到对比卡上，松手，弹出一行小字：**连接为「回应」？** 你点了是。

### 场景 B — 圈选即交代
你想让 Coworker 帮你理清左边那堆乱卡。你按住鼠标圈出它们，松开后圈的右下角浮出一个小胶囊：
> **12 张卡被选中** · 交给 Mira · 附带圈注
你点"交给 Mira"，输入框里已经写好"整理这堆，找出三条主线"。你补了一句"别动我的排布"，回车。
- Mira 的结果以**新卡组**落在选区右侧空白处，不覆盖任何东西。
- 你原来的排布一个像素没变。

### 场景 C — 想法转正
你在空白处随手写了行字："要不要做对比视图？" 这只是个念头。下午开完会你觉得它值得留：
- 你右键这行字 → **保留** → 它变成一张正式的便签卡（可被搜索、可被 `@` 引用）。
- 其他随手画的线和字都还在——它们属于这张桌子，不需要你清理。

## 3. 从场景里长出来的原则

| 原则 | 场景出处 | 反面（不做） |
|---|---|---|
| **位置有意义**：摆放在哪、挨着谁，就是思考的一部分 | A 两堆卡 | 自动重排、"整理我的桌面"按钮 |
| **空间记得一切**：笔迹、圈注、随手写，都是桌子的一部分 | C 没人清理草稿 | 自动过期、强制归档 |
| **操作即语义**：拖、圈、连、写，每个手势都有明确含义，松手时才确认语义 | A 拖问号→"连接为「回应」？" | 静默猜测用户意图 |
| **圈选即交代**：选中 + 一句话 = 一份可以交给 Coworker 的工单 | B | 菜单里找"委派"功能 |
| **结果落回空间**：Coworker 的产出回到桌面上，成为你可以继续摆弄的卡 | B 新卡组落右侧 | 只在聊天里给一段文字 |
| **不动你的排布**：agent 的产物永远落在新位置 | B "别动我的排布" | agent 自动归类你的卡 |
| **转正是你的动作**：随手写的东西要经过你才成为正式对象 | C 右键"保留" | 自动生成正式卡片 |

## 4. 空间的构成（界面上有什么）

| 东西 | 是什么 | 界面上的原话 |
|---|---|---|
| **桌面** | 这块无限的工作面本身 | "这个空间" |
| **材料卡** | 便签、文件卡、论文卡、Artifact 卡——任何被带进来的东西 | 卡名 + 来源角标 |
| **痕迹** | 手绘线、圈、箭头、随手写的字 | 笔迹，可被选中 |
| **区域** | 你框出来的一片地方，可以起名（"证据"、"待办"） | 区域名 |
| **连接** | 卡与卡之间带名字的线（"回应"、"矛盾"、"支撑"） | 线上的小标签 |
| **材料栏** | 桌面左侧的抽屉：搜索、拖入文件/笔记/网页 | "把材料带进来" |

带进来（bringing in）= 从材料栏拖一张卡到桌面上。想（thinking with）= 摆放、圈注、连线。塑造（shaping）= 分区、命名、折叠、排布。

## 5. 手势词汇表

| 手势 | 语义 | 松手时发生什么 |
|---|---|---|
| 拖卡 | 放置 | 直接落下，无确认 |
| 圈选（含部分笔迹） | 交代/聚焦 | 浮出胶囊：**N 项被选中 · 交给 [Coworker] · 附带圈注** |
| 从卡拖出线到另一卡 | 提出关系 | 弹一行小字：**连接为「回应」？**（词表可换） |
| 写/画 | 随手记 | 直接是痕迹，不弹任何框 |
| 右键痕迹/便签 | 提升 | 菜单：**保留为便签卡 / 复制 / 删除** |
| 框出区域 | 分组 | 区域线出现，可命名 |
| 双击区域名 | 改名 | 就地编辑 |
| 拖到区域边界内 | 归入 | 落下即可，区域随之长大 |
| ⌘Z | 撤销 | 一切操作可撤销 |

**设计红线**：任何会改变"你的东西是什么"的猜测（关系语义、转正、归类），都要在松手那一刻用一行字问你。放置和书写从不问。

## 6. 与 Coworker 在空间里协作

- **交代**：圈选 + 一句话（见场景 B）。附带圈注是默认勾选项，不带就说"不带圈注"。
- **结果落位**：Coworker 产物以**新卡组**落在选区旁的空白处，带头像角标。永不覆盖、永不重排你的卡。
- **互相看见**：Mira 动过的卡有细角标；点开看"她改了什么、为什么"（一行理由）。你动了 agent 卡组里的卡，它下次工作时知道——角标会标"你改过"。
- **拒绝是常态**：agent 卡组整组可拖进"回收角"（区域的一种），一句话不问。

## 7. 空间的记忆（回来时什么样）

- 一切原样：卡、排布、痕迹、区域、连线、agent 卡组。
- 唯一"消失"的方式是你的动作：删除、拖进回收角、折叠进区域。
- 时间信息只出现在一处：卡片角落的"3 小时前 / 昨晚"，不打扰。
- **组织代替清理**：乱了就框区域、起名字、折叠——像整理真实的桌子。

## 8. 与其他视图的关系

- 空间是**环境**；列表、时间线、搜索是它的**投影**（同一张桌子的账本视角）。
- 从列表拖一项进空间 = 带进材料；从空间右键卡片 = "在列表中查看"。
- 对话（Home Conversation）是桌子旁边的电话：圈选后可"带去对话"，对话结论可"放回桌面"。

## 9. 视觉基调（静谧计算美学落在空间）

- 桌面是纸的底色；卡是纸片（1px 边、无阴影堆叠感）。
- 色彩只给三样：痕迹（铅笔色）、agent 角标（一个颜色）、区域轮廓（极淡）。
- 没有工具栏轰炸：手型/笔/线三种，按住右键出环形菜单。
- 动效只有落纸的 120ms。

## 10. 非目标

- 不是白板协作工具（不做人对人实时涂鸦同步）。
- 不是"AI 自动整理桌面"。
- 不做装饰性无限画布噱头（星空背景、缩放动效）。
- 不在空间里塞聊天窗——电话在旁边，不在桌上。

## 11. 开放设计问题（下一轮）

1. 圈选胶囊的默认 Coworker 是谁（上一个用过的？空间指定的？）
2. 区域能否嵌套；折叠的视觉语言。
3. 痕迹的"转正"是否也支持转成卡组/区域（不只单卡）。
4. agent 卡组的生命期：是普通卡组还是特殊对象（可"采纳进我的排布"？）。
5. 空间与 Q-E（持久阶梯）的关系：C2 下是否还需要 kept/canonical 分层，还是"保留"即全部。
6. 移动端/触屏上的手势词汇（写画为主）。
