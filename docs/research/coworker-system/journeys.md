## 规则（§31）

- 断言查 DOM 真实状态，不做截图比对；每步一行 `✓/✗`。
- AI 只换远端（本地 stub）：蓝图出 JSON 草案、校验出 verdict——管线是真代码。
- 发现偏差二选一（改设计或改实现），不留"已知问题"。
- 对抗路径（断网/半交接/越权/断链/连点）在 `src/services/collaboration/session.integration.test.ts`（自动化断言层），不进本 DOM 旅程。
