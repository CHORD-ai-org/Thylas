## 制作说明

- **版式**：静谧计算美学——纸底、1px 线、表格优先、颜色只给标注标签；A4 竖版。
- **配图**：三张项目桌面示意图（结构/工作态/状态流）+ Workspace⊃Project 层次图 + 里程碑图。
- **PDF 管线**：md 成稿 → workbuddy-docx（研报模板）→ 导出 PDF；图先转 SVG/PNG 插入。
- **写作顺序建议**：Part II → III → IV（核心）→ V → I（最后写开场）→ VI/附录。
- **篇幅纪律**：正文 ≤ 24 页；写完按文字预算自查一遍行话。
