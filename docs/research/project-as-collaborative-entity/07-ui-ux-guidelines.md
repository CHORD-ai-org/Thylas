## A. 交付检查表（Pre-delivery Checklist → Thylas 版）

| 源条目 | Thylas 落点 |

| 图标用 SVG，不用 emoji | Rail/按钮/状态全 SVG；批注与角标禁 emoji |
| 可点元素全部 cursor-pointer | 卡、芯片、胶囊、窄栏条目 |
| 交互时序按平台与用户偏好 | 落纸 120ms；`prefers-reduced-motion` 下直接落位无动效 |

## B. 韧性文本与紧凑 UI（5 条 → 文字预算的增补）

1. 标题平衡换行只是渐进增强——设计必须在自然换行下成立。
2. 必要文本在窄宽/浏览器缩放/用户间距覆盖下不得裁切；长 URL/locator 可安全换行。
3. 芯片组换行或 `+n` 展开；不可避免的截断必须给键盘/指针/触摸同等的完整值路径。→ 顶栏参与者头像 `+n`、材料栏、圈选胶囊。
4. **徽章含义不能只靠颜色**：琥珀角标必须配形状或文字；实时计数要有语境（"3 项待审"，不是"3"）。
5. 快速连击可取消动画，但最终语义状态/焦点/内容必须正确——落纸中再点另一张卡，最终停在后者。

## C. 表单与微交互（141 条 UX 准则中与 Thylas 相关项）

- 表单错误：修复后即清错、**保留用户输入**、未保存离开要提醒、操作可撤销、对话框焦点管理。→ 新建项目/连接文件夹/派工表单。
- 长操作可取消（repo 扫描、连接器探测）。
- **IME 安全的 Enter**：对话抽屉/批注输入，中文输入法组字中按 Enter 不得触发发送（`isComposing` 判定）。中文用户必做。

## D. 设计系统纪律（Design System Generator 的产出结构）

- 每个界面决策成套给：Pattern / Style / Colors / Typography / Effects / **AVOID 清单**。
- Thylas AVOID 清单：AI 紫渐变、玻璃拟态、装饰性动效、emoji 图标、颜色-only 语义、彩虹配色、营销式大标题——与静谧计算美学一致。
- `design/tokens.css` 为唯一色/字阶来源（D3 既有）；新增 UI 颜色必须进 tokens。

## E. 与现有红线的冲突裁定

| 潜在冲突 | 裁定 |
|---|---|
| prefers-reduced-motion vs 落纸 120ms 红线 | 保留动效但尊重系统偏好：reduced-motion 下直接落位 |
| 响应式断点 vs 桌面优先（D7） | 只做桌面两档，窄窗降级列表，不做移动布局 |
| 80 种风格库 vs 静谧计算 | 不引入外部风格；只取检查表与韧性/可及性规则 |
