## P0 骨架（数据先行）

- **P0-1** Project 实体：`projects` / `project_connections` / `project_members` 三表 + migration（`server/persistence/schema.ts`）。字段最小集：id、name、summary、workspace_id、state、时间。
- **P0-2** 未归类迁移：现有 workspace 内容（files/boards/processes/notes）挂 `project_id`（可空 = 未归类暂存区）。
- **P0-3** 连接器·本地文件夹：登记引用（路径 + kind），不搬文件；失效检测（改名/移动 → 标"待修复"）。
- **关卡**：连接 → 解析 → 改名 → 标失效 → 修复，全链路；项目卡（名字+id）全程存活。

## P1 项目地图

- **P1-1** 列表视图：项目卡（名字/摘要/参与者/活跃度），先列表后画布。
- **P1-2** 项目生命周期：创建/归档/删除（软删 30 天）；菜单进 03 的卡片右键。
- **P1-3** 连接器·GitHub repo（第二个 kind，验证引用模型的通用性）。
- **关卡**：三 repo 成一张"Lemma"卡；归档卡进归档视图。

## P2 项目桌面（含两条修订）

- **P2-1** 桌面路由 `/w/:wsId/p/:projectId` + C2 空间复用（boards 挂进项目）。
- **P2-2** 四区布局：顶栏/材料栏/桌面/讨论窄栏；落纸 120ms；视口记忆（上次排布恢复）。
- **P2-3**【修订①】**对话抽屉（随时调取的 agent chat）**：⌘J / 顶栏气泡唤起右侧抽屉；不遮桌面、收起后排布不动；圈选 → "带去对话"入口；对话结论 → "放回桌面"。实现上即 Home Conversation 的桌面常驻形态（与 home-interaction 会师点）。
- **P2-4**【修订②】**文字预算**（见下节），UI 文案清单 + 走查关卡。
- **关卡**：排布恢复 = 每像素还原；空状态一行字；⌘J 三步内可对话；文案走查零超长。

## P3 上下文与引用

- **P3-1** 项目 Context 分区：先本地存储，接口留 GSC 兼容（project 级 scope）。
- **P3-2** `@` 调用项目/材料（接 `src/lib/invoke.ts`）。
- **P3-3** 跨项目引用：条目级引用边，不复制；A 更新 → B 标"已更新"。
- **关卡**：两项目共享一条 Context 且可解析（02 场景 4）。

## UI 文字预算（修订②，防冗余硬规则）

| 位置 | 预算 | 反例 |
|---|---|---|
| 桌面卡 | 只有名字 + 角标，零描述段 | 卡上写"这是一个关于…的笔记" |
| 痕迹/批注 | ≤ 12 字/条 | 圈注旁写整段分析 |
| 窄栏活动 | 一行一事 ≤ 20 字："谁 · 做了什么 · 多久前" | 五行流水账 |
| 顶栏 | 项目名 + ≤ 6 字状态词 | 副标题 + 面包屑 + 描述 |
| 空状态引导 | 一行 ≤ 20 字 | 三段新手引导 |
| 按钮/菜单 | 动词 2–4 字 | "点击这里开始创建您的项目" |
| 一切解释 | tooltip / 详情面板 / 文档 | 主界面常驻说明文字 |

**走查方法**：设计定稿前导出全部 UI 文案清单，逐条过预算——超长即砍。对齐"交付物要短不要全"。
