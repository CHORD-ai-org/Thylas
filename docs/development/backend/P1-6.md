## 2. 数据模型

`server/persistence/schema.ts` 加了 `files` 表，`npm run db:generate` 产出 `0001_classy_bedlam.sql`：

```
files {
  id            text PK
  workspace_id  text NOT NULL
  folder_id     text NULL
  name          text NOT NULL
  kind          text NOT NULL
  size_bytes    integer NOT NULL
  storage_key   text NOT NULL   // <wsId>/<fileId>
  created_at    timestamptz NOT NULL default now()
  updated_at    timestamptz NOT NULL default now()
  deleted_at    timestamptz NULL     // 软删，对齐 SP-04b tombstone
}
// index: (workspace_id, folder_id)
```

`STORAGE_DIR` 加进 `server/config.ts`（唯一 reader）；`STORAGE_BUCKET` 保留给未来 S3，本轮不读。

## 3. API 与落盘

| 文件 | 职责 |
| --- | --- |
| `src/lib/files.ts` | 唯一契约：`FILES_PATH`、header 名、`FILE_MAX_BYTES = 100MB`、`FileDto`、`FileErrorKind`、`fileFailure()` / `statusForFile()`、路径段 / 文件类型 / 文件名校验 |
| `server/http.ts` | `pipeBodyToFile()`：流式写盘、计数、超限删半成品；`flags:'wx'` 不覆盖已有 id |
| `server/storage/local.ts` | 本地字节仓库：write / open / discard / keyFor；路径段 `^[A-Za-z0-9_-]{1,128}$` 防穿越 |
| `server/routes/files.ts` | 5 个端点 + session → membership → write |
| `server/router.ts` | `/api/files*` 分发 |

端点（raw body + headers，不引 multipart 解析依赖）：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/api/files` | `x-thylas-file-name` / `-kind` / `-workspace` / `-folder`；流式落盘 + 写元数据 |
| `GET` | `/api/files?workspaceId=` | 按成员工作区过滤，排除软删 |
| `GET` | `/api/files/:id` | 元数据 |
| `GET` | `/api/files/:id/content` | 字节流下载，`filename*=UTF-8''…` |
| `DELETE` | `/api/files/:id` | 软删，不立刻删字节 |

全部复用 P1-5：无 session 401，非成员 403，绝不返回空列表冒充无权限。无 `DATABASE_URL` 或 `STORAGE_DIR` 时 503 `not_configured`。
